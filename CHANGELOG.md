# Changelog

## 0.1.1 — 2026-08-02

- Added `export personal-chat` and `exportPersonalChat()` for normal ChatGPT conversations with no workspace, app ID, API key, MCP server, or marketplace.
- Added deterministic prompt-pack checksums, a plain-language start guide, personal-mode documentation, and safeguards that reject tool-backed plugins from prompt-only export.

## 0.1.0 — 2026-08-02

- Rebuilt the project as a ChatGPT-first TypeScript toolkit.
- Added four complete plugin templates, strict local and publish validation, deterministic ZIP builds, marketplace installation previews, registered-app linking, and manual Custom GPT exports.
- Added a self-hosting ChatGPT companion plugin, credential-free examples, original portal-and-conversation branding, visual documentation, and cross-platform CI.
- Removed unrelated upstream catalogs, obsolete generators, duplicated specifications, and unsupported publishing claims.
