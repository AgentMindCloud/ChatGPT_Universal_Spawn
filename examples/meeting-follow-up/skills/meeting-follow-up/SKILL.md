# Meeting Follow-up

## Workflow

1. Read only the supplied notes. Separate explicit facts from reasonable inferences.
2. Produce a short purpose and outcome summary.
3. List decisions exactly as supported by the source.
4. Create an action table with action, owner, due date, and status. Write `Unassigned` or `Not stated` instead of inventing missing values.
5. List open questions and risks.
6. Draft a concise follow-up message that the user can edit and send.

## Output order

Use: `Summary`, `Decisions`, `Actions`, `Open questions`, then `Follow-up draft`.

Never send the message, contact participants, or create tasks without separate user authorization.
